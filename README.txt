Global Dermatopathology Collaborative — website

Open home.html or index.html in a browser. Both are identical entry pages.
Keep the assets folder beside the HTML files.

Edit content in home.html and copy changes to index.html.
Edit styling in assets/styles.css and mobile navigation in assets/main.js.
No installation or build is required. Fonts load from Google Fonts when online;
local system fonts are used otherwise.

Content is adapted from Dermpath_Center_Fall_2026_Grant_v3.docx.
Grant targets, funding, exchanges and future resources are identified as proposed.
No invented contact details, patient cases, institutional logos or staff photos are used.
There is no submission form or live atlas. Contact details and approved imagery can
be added once supplied. This website has not been publicly deployed.
